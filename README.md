### 🔥 Projet phare : Abide — *Ta Bible, ta prière, ton guide au quotidien*

Une app mobile **SaaS freemium** de croissance spirituelle chrétienne, pensée pour les réalités culturelles africaines. Pas un side-project, un vrai produit avec un vrai problème résolu.

**Le problème résolu :**
- Manque de régularité dans la lecture/prière quotidienne
- Absence de structure personnalisée et progressive
- Contenu biblique peu adapté aux réalités africaines

**Les fonctionnalités clés :**
- 📖 Lecteur Bible complet — 5 traductions, 100% hors ligne
- 🎧 Audio Bible humain synchronisé au verset (background audio)
- 🤖 Guide IA pastoral — 4 modes (enseignement, prédication, méditation, théologie)
- 📅 14 parcours de lecture thématiques
- 🙏 Journal de prière, tracker de jeûne, défis spirituels
- 🔥 Gamification — streaks, badges, notifications

**Stack technique :**
- **Mobile** : Vue 3 + Ionic + Capacitor 6 + SQLite
- **Backend** : Supabase (PostgreSQL, Auth, Edge Functions, pgvector)
- **IA** : OpenRouter (GPT-4o-mini / Gemini Flash) + OpenAI TTS
- **Audio** : BibleBrain API + Cloudflare R2
- **Paiements** : KKiaPay/FedaPay (Android) + RevenueCat/IAP (iOS)
